# DecodeLabs — Project 2: The Server Commander

## Overview

A static webpage hosted on an AWS EC2 Ubuntu Linux server using Apache.

## Technologies

* AWS EC2
* Ubuntu Linux
* Apache Web Server
* HTML and CSS
* SSH

## Deployment

1. Launched an EC2 Ubuntu instance.
2. Configured SSH (port 22) and HTTP (port 80).
3. Connected to the server using SSH.
4. Installed Apache.
5. Deployed the custom webpage.
